# UsageWidget

Windows 작업표시줄에 Claude Code / Codex 사용량(남은 양)을 원형 그래프와 %로 표시하는 위젯.
Claude 출력 속도(⚡ t/s)도 함께 표시한다.

## 공유 시 전달할 파일

- `UsageWidget.exe` — 이것만 있으면 된다.
- `statusline.ps1` — 선택 (아래 설치 3번, 조회 실패 대비용)

`config.ini`, `claude-usage.json`은 PC별 위치·개인 사용량이므로 공유하지 않는다. 없으면 자동으로 만들어진다.

## 요구 사항

- Windows 10/11 (.NET Framework 4.8 기본 포함, 별도 설치 불필요)
- Claude 값: 해당 PC에서 Claude Code(CLI 또는 데스크톱 앱 Code 탭)에 로그인되어 있어야 한다.
- Codex 값: 해당 PC에서 Codex를 한 번 이상 사용했어야 한다. 안 쓰면 우클릭 → 표시할 AI에서 끈다.

## 설치

1. 쓰기 가능한 폴더(예: `C:\Users\<사용자>\usage-widget`)에 `UsageWidget.exe`를 넣는다.
   설정이 exe 옆 `config.ini`에 저장되므로 `Program Files` 같은 쓰기 제한 폴더는 피한다.
2. `UsageWidget.exe` 실행. 처음 실행 시 SmartScreen 경고가 뜨면 "추가 정보 → 실행".
   - 처음 위치는 작업표시줄 오른쪽 트레이 왼편. 드래그로 옮긴다.
   - 부팅 시 자동 실행: 우클릭 → "Windows 시작 시 자동 실행" 체크. 체크를 끄면 등록도 삭제된다.
     exe를 다른 폴더로 옮겼다면 다시 체크해야 새 경로로 등록된다.
3. (선택) Claude Code 상태줄 연동: Claude 값은 로그인 정보로 자동 조회되므로 필수는 아니다. 조회 실패 대비용으로 쓰려면 `~/.claude/settings.json`에 아래 항목을 추가(또는 기존 `statusLine` 교체). 경로는 실제 위치로.

   ```json
   "statusLine": {
     "type": "command",
     "command": "powershell -NoProfile -ExecutionPolicy Bypass -File \"C:/Users/<사용자>/usage-widget/statusline.ps1\""
   }
   ```

   - 기존에 쓰던 상태줄 스크립트가 있다면 `statusline.ps1` 맨 아래 `$next` 경로를 그 스크립트로 바꾼다. 없으면 그대로 둬도 된다.

## 사용법

- 기본 표시: `Claude 65% 주 65% · ⚡ t/s 116 · 작업 중 4m 20s · Codex 100% 주 95%`
  - 큰 숫자 = 5시간 한도, `주` = 주간 한도
  - 작업시간: 프롬프트 입력부터 최종 응답까지(도구 실행 포함). 진행 중이면 "작업 중"으로 1초마다 증가, 끝나면 "작업시간"으로 총 시간 표시
- 마우스 올리기: 5시간/주간 사용률, 리셋 시각, 갱신 시각, 최근 요청 t/s와 최근 10분 평균, 작업시간
- 드래그: 위치 이동 (오른쪽 끝 기준으로 저장되어 폭이 바뀌어도 왼쪽으로 늘어남)
- 가장자리·모서리 드래그: 위젯 크기(글자·그래프 전체) 60~250% 확대/축소. 좌우·위아래 끝과 네 모서리(대각선) 모두 가능, 반대쪽은 고정
- 작업 완료 알림: Claude 세션의 작업(턴)이 끝나면 위젯 위(위젯이 화면 위쪽이면 아래)에 10초간 카드 표시
  - 내용: 작업시간, 세션 제목, 프로젝트 폴더, 완료 시각. 클릭하면 닫힘, 최대 4개까지 쌓임
  - 직접 중단(Esc)한 작업, 위젯 실행 전에 끝난 작업은 알리지 않음
- 우클릭:
  - 표시할 AI 선택 (+ Claude 출력 속도·작업시간 켜기/끄기)
  - 작업 완료 알림: 켜기/끄기, 알림 소리, 깜박임(나타날 때 5번, 기본 켜짐), 알림 크기(80~200%, 선택 즉시 미리보기), 미리보기
  - 5시간 / 주간 / 5시간 + 주간 함께 표시, 사용한 양으로 표시
  - 모양: 글자 색상, 배경 색상, 배경 불투명도(0~100%), 크기(80~200% 프리셋), 기본값으로
  - 새로고침, 위치 초기화, Windows 시작 시 자동 실행, 종료

## 참고

- Claude 값은 2분마다 Claude Code 로그인 정보(`~/.claude/.credentials.json`)로 `/usage`와 같은 사용량 조회 API를 호출해 가져온다.
  조회 전용이라 토큰·한도를 소모하지 않으며, 로그인 토큰은 api.anthropic.com에만 전송된다.
  조회가 실패하면(비공식 엔드포인트 변경, 토큰 만료 등) `claude` CLI 상태줄이 저장한 값 중 더 최신 것을 쓴다.
- Claude t/s는 `~/.claude/projects`의 세션 기록(CLI·데스크톱 앱·서브에이전트 모두)에서 계산한다.
  요청마다 `출력 토큰 ÷ (요청 시작 ~ 마지막 블록 완료)`이므로 첫 토큰 대기시간이 포함된 추정치다.
  statusLine 설정 없이도 동작하며, 마지막 응답이 15분 넘게 지나면 흐리게 표시된다.
- 소스 수정 후 재빌드: `powershell -ExecutionPolicy Bypass -File build.ps1`
