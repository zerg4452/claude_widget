## 변경

사용자 첨부 화면의 프로젝트 내 세션명을 알림 제목으로 표시한다. 실제 CODEX_HOME/session_index.jsonl에서 현재 대화 ID의 thread_name이 `코덱스 위젯 작업시간 노출 수정`임을 확인했다.

- UsageWidget.cs: session_meta.id로 세션을 식별하고 session_index.jsonl의 thread_name을 읽는다. 중복 ID는 뒤에 기록된 최신 이름을 사용한다. 사용자 요청과 세션명은 별도 필드로 유지하며 카드에서는 세션명을 우선한다. 이름이 없으면 기존 제목 대체 동작을 유지한다.
- 이름 목록은 폴링마다 읽기 공유 모드로 조회해 로그 캐시가 유지되어도 새 이름이 적용된다. 인증·세션·이름 목록에 쓰지 않는다. 외부 패키지와 DB 접근을 추가하지 않았다.
- CodexMetricsTests.cs, NotificationIntegrationTests.cs: 이름 조회·변경·목록 부재·실제 기록 및 실제 카드 제목 검증 추가.
- README.md와 배포 안내 갱신, 실행 파일과 ZIP 재생성.

## 검증

- build.ps1 컴파일 성공.
- test.ps1 -CodexSessions: 33개 검증 통과.
- 통합검증: 실제 RefreshData → ShowToast 경로의 카드 제목이 사이드바 세션명과 같음을 확인했다. 중복 알림·중단 억제도 통과했다.
- 동일 카드의 DrawToBitmap 렌더를 시각 확인했다. 첨부 화면과 같은 세션명과 프로젝트 정보가 표시되었다. 이는 렌더 검증이며 상시 위젯의 실제 사용자 완료 순간을 캡처한 결과는 아니다.
- adversarial-review: 실제 변경·세션 ID 매칭·이름 조회 실패·기존 요청 제목 보존·알림 조건을 검토했다. critical/high 발견 없음.

## 제한

- Codex가 session_index.jsonl에 반영한 이름을 사용한다. 앱 내부에만 저장되고 이 목록에 반영되지 않은 이름은 조회할 수 없다.
- 카드의 기존 폭을 유지하므로 긴 세션명은 화면에서 말줄임된다. 세션명 자체는 80자로 자르지 않는다.
- 커밋·푸시는 수행하지 않는다.
