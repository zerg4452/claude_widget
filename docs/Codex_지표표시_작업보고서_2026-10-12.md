# 작업 보고서: Codex t/s와 작업시간 표시

- 작성일: 2026-10-12.
- 작업자: Codex.

## 1. 작업 개요

실행 중인 프로그램은 `%USERPROFILE%\usage-widget\UsageWidget.exe`였다. 기존 소스는 Codex 사용 한도만 읽고, 속도·작업시간의 수집·렌더링·툴팁·초 단위 타이머는 Claude에만 연결되어 있었다.

## 2. 적용한 규칙

- Superpowers 선택: 사용안함.
- 실제 위젯 저장소의 AGENTS.md / CLAUDE.md / .cursor 규칙: 없음.
- 유사 과거 작업보고서: 없음. 기존 README와 Claude 파서·렌더링 패턴을 참고했다.
- 현재 채팅의 design_refs 게임 에셋 디렉터리는 작업 대상이 아니므로 수정하지 않았다.
- ez-task 흐름에 따라 최소 변경과 검증을 수행하고 adversarial-review Fix Mode로 직접 검토했다.

## 3. 변경 내역

- `UsageWidget.cs`: Codex 로컬 JSONL 증분 파서와 캐시, 메인 세션의 작업 시작·완료·중단 처리, 중복 토큰 이벤트 제거, 도구 실행 대기를 분리한 속도 추정, AI별 렌더링·툴팁·초 단위 타이머 연결.
- `build.ps1`: Windows .NET Framework에 포함된 System.Web.Extensions JSON 파서 참조 추가. 외부 패키지 없음.
- `CodexMetricsTests.cs`, `test.ps1`: 합성 로그 기반 회귀검증 및 선택적 실제 로그 검증.
- `README.md`: 표시 내용, 계산 의미, 조회 범위와 검증 방법 갱신.
- `UsageWidget.exe`: 빌드 후 기존 실행 파일 백업을 보존하고 교체한다. 개인 config.ini와 claude-usage.json은 배포 복사 대상에서 제외한다.

## 4. 빌드·테스트 검증

- `build.ps1`: .NET Framework C# 컴파일 성공.
- `test.ps1 -CodexSessions %USERPROFILE%\.codex\sessions`: 17개 검증 통과.
- 검증 범위: 기록 없음, 도구 대기 제외, 중복 이벤트, 가중 평균, 완료 시간, 캐시, 새 작업, 이전 작업 완료 이벤트, UTF-8 부분 기록, 중단, guardian 제외, 파일 축소, 잘못된 JSON, 토큰 카운터 초기화, 실행 중 작업 우선, 방치 세션, Unix 시작·완료 시각, 토큰 이벤트 이후 도구 결과, 실제 Codex 로그.
- 실제 기록에서 양수 t/s와 현재 대화의 진행 중 작업시간을 확인했다. 변동하는 순간 수치를 고정 기대값으로 사용하지 않았다.
- Computer Use로 동일 WidgetForm 렌더링을 사용한 별도 검증 창에서 Codex t/s와 작업 중 시간이 표시됨을 확인했다. 실제 상시 위젯은 제목 없는 toolwindow라 Computer Use 창 목록에 나오지 않는다. 검증 창의 캡처를 실제 상시 위젯의 캡처로 표현하지 않는다.

## 5. 검토 결과

- adversarial-review: 완료된 실제 diff와 호출부를 직접 검토했다. 배포를 막는 critical/high 발견 없음.
- 세션 메타데이터로 보조 세션을 제외하고, JSON 봉투 타입을 검사하므로 도구 출력에 포함된 이벤트 문자열을 실제 이벤트로 오인하지 않는다.
- 읽기 공유 모드와 줄바꿈 경계에서의 오프셋 갱신으로 쓰기 중인 기록을 안전하게 재조회한다. 개인 기록·인증 파일을 수정하지 않는다.
- 초기 추가 테스트는 동일 경로를 더 긴 내용으로 덮어쓰는 fixture 때문에 실패했다. 실제 append 기록을 모사하도록 독립 fixture 경로로 고친 뒤 전체 재검증했다. 일반적인 append와 길이가 줄어든 로그를 지원하며, 같은 파일을 더 긴 완전히 다른 내용으로 덮어쓰는 경우는 증분 캐시의 제한이다.

## 6. 남은 제한

- t/s는 로그 기반 추정치이며 실제 스트리밍 순간 속도는 아니다.
- 14개 날짜 폴더, 최근 24시간, 메인 세션 최대 8개 조회와 30분 무기록 종료 추정이 적용된다.
- Codex 완료 알림 추가는 이번 범위에 포함하지 않았다.
- 커밋·푸시는 수행하지 않는다.

## 8. 배포용 패키지

- 사용자 요청에 따라 `dist/UsageWidget-2026-10-12.zip`과 최신본 `dist/UsageWidget.zip`을 생성했다.
